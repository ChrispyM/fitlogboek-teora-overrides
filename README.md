# Fitlogboek: aanpassingen op wger

[Fitlogboek](https://fitlogboek.nl) draait op [wger](https://github.com/wger-project/wger), onder de GNU AGPLv3.

Deze repo bevat de aanpassingen van Teora op wger 2.7: de template-overrides, vertalingen en instellingen. De templates zijn afgeleid van wger; de rest van de code is ongewijzigd wger.
Het logo en de naam Teora zijn eigendom van Teora en vallen niet onder de licentie.

## Gebruik

Mount deze map in de `web`-container op `/home/wger/src/teora` en zet `DJANGO_SETTINGS_MODULE=teora.settings`.
